# SNAILS - Ferret Farm Live Streaming Platform

## 🐌 About SNAILS

SNAILS is a revolutionary live streaming platform dedicated to ferret farming enthusiasts. Watch our adorable ferrets 24/7 through high-quality live streams while participating in our growing crypto community.

## 🌐 Website Features

- **Live Streaming**: 24/7 ferret farm broadcasts
- **Community**: Join our active community on X (Twitter), Telegram, and Discord
- **Token**: $SNAILS utility token on Solana blockchain
- **Modern Design**: Responsive, animated interface inspired by our brand colors

## 🚀 Quick Start

The website is ready to use! Simply open `index.html` in your browser.

### Customization Required

Before launching, update the following links in `index.html`:

1. **Twitter/X Handle** (line 89):
   ```html
   https://twitter.com/your-snails-handle
   ```

2. **Telegram Group** (line 93):
   ```html
   https://t.me/snailscommunity
   ```

3. **Discord Server** (line 97):
   ```html
   https://discord.gg/snails
   ```

4. **Token Address** (lines 72, 76):
   ```html
   https://dexscreener.com/solana/YOUR_TOKEN_ADDRESS_HERE
   https://raydium.io/swap/?inputMint=sol&outputMint=YOUR_TOKEN_ADDRESS_HERE
   ```
